# Build Your Own AI Agent

A free, beginner-friendly course for building an AI agent from zero, in English, Nepali and Chinese.

Open the course: https://wangdencerpa12345-star.github.io/build-your-own-ai-agent/

- Practice Python right in the browser (Pyodide)
- Glossary, resources and custom backgrounds
